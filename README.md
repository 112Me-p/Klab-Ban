# กลับบ้านข้าวมันไก่ — Clean Build

Fresh clean build for a **new GitHub repository**. It does not depend on V1/V2/V2.1 files.

## Before uploading to GitHub
Copy your original DB Urbanist X font files into:

`assets/fonts/`

with these exact names:
- `DB Urbanist X.woff2`
- `DB Urbanist X Bd.woff2`
- `DB Urbanist X Li.woff2`

Then upload the whole project to the root of the new repository and enable GitHub Pages from the main branch/root.

## What was rebuilt
- Clean font declarations: one Light, one Regular, one Bold declaration only
- Desktop visual direction retained
- Mobile hero is a different composition, not a scaled-down desktop layout
- Mobile typography uses readable line-height and no Thai letter-spacing compression
- Menu size selection + Add to Cart
- Rice cup 15 THB
- Quantity controls, remove item, total, copy order, LINE share
- Signature sauce section
- Six-part brand scrollytelling
- Gallery and responsive mobile cart
